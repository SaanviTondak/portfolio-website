# Project preview images

Drop your 5 project preview images here, named to match `src/data/content.js`:

    public/projects/project-1.jpg
    public/projects/project-2.jpg
    public/projects/project-3.jpg
    public/projects/project-4.jpg
    public/projects/project-5.jpg

- Recommended size: **1600 × 1000** (16:10), JPG or WEBP, < 400 KB each.
- If an image is missing, the card shows a labelled placeholder instead of
  breaking — so you can add them one at a time.
- To change filenames, edit the `image` fields in `src/data/content.js`.
